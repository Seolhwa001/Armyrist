Armyrist Patch 034

1. 체크리스트 항목 일반 터치
- 일반 모드: 항목 카드 터치 -> 기존 편집 팝업
- 그룹 지정 모드: 터치 -> 선택/해제
- Long Press Drag: 순서 변경
- 상태 버튼: 기존 상태 변경 유지

2. 기본 결과문 제목 제거
- 실셈 / 체크리스트 / 시간계획 Result.body에서 제목 자동 출력 제거
- Result.title 값 자체는 유지
- {제목} 변수는 계속 정상 작동
- {전달내용}에는 제목 없는 본문이 들어감
- 양식 없음 선택 시 제목 없는 기본 결과문만 표시

변경 파일 5개만 포함.
