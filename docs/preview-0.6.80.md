# 0.6.80 검수 변경 사항

- 시간표에서 일정 영역과 실시사항 영역을 나누고 제목·시각·시간선 대비를 높였습니다.
- `점 + 실시사항` 모드에서는 실제 시각의 점과 내용 카드를 연결합니다. 가까운 항목의 카드는 겹치지 않도록 배치하며 항목이 많은 시간대는 높이를 늘립니다. 같은 분의 항목은 개수를 표시하고 누르면 각각 선택할 수 있습니다.
- `점만` 모드로 전환할 수 있으며 표시 설정은 앱에 저장됩니다. 절반 요약이 열리면 시간표는 점만 표시하여 공간을 확보합니다.
- 왼쪽 스와이프로 실시사항 요약 열기, 오른쪽 스와이프로 닫기를 지원합니다. 편집 중에는 텍스트 선택을 보호하기 위해 저장·취소 후 스와이프를 사용합니다.
- 점의 색상 변경, 길게 눌러 여러 항목 선택·휴지통 이동 기능을 유지했습니다.

기존 0.6.79 검수 앱과 동일한 패키지·서명을 사용합니다. 정식 앱과는 별도의 검수 앱이며 GitHub 정식 배포 전 확인용입니다. 실제 휴대폰의 제스처·큰 글꼴 설정은 검수가 필요합니다.
