Armyrist 0.6.40–0.6.41

이번 업데이트는 시간계획 관리 기능 확장과 Armyrist 공통 UI 안정화를 중심으로 진행했습니다.

[시간계획 폴더 기능]
- 시간계획을 여러 개 선택하여 폴더로 묶어 관리할 수 있습니다.
- 카드의 이동 핸들은 기존처럼 순서 변경에 사용하며, 카드의 다른 영역을 길게 누르면 다중 선택 모드로 진입합니다.
- 새 폴더 생성 및 기존 폴더로 이동을 지원합니다.
- 폴더 이름 변경 및 삭제를 지원합니다.
- 폴더를 삭제해도 내부 시간계획은 삭제되지 않고 전체 목록으로 돌아갑니다.
- 갤러리에서 원하는 이미지를 선택해 폴더 대표 이미지로 사용할 수 있습니다.
- 선택한 이미지는 앱 내부 저장소에 보존됩니다.

[시간계획 사용성 개선]
- 시간계획 이름 변경 결과가 목록 UI에 즉시 반영되도록 수정했습니다.
- 폴더 내부에서 휴대폰 시스템 뒤로가기를 누르면 홈이 아니라 시간계획 전체 목록으로 돌아가도록 수정했습니다.
- 다중 선택 상태에서는 뒤로가기를 누르면 먼저 선택 모드가 해제됩니다.

[Armyrist 공통 UI 정리]
- 자동 업데이트 탐지 Dialog를 현재 Armyrist Design Language에 맞게 정리했습니다.
- 실셈과 체크리스트의 데이터 불러오기 및 휴지통 UI를 시간계획 화면과 통일했습니다.
- 버튼 외곽선의 명암과 표현을 통일했습니다.
- 시간계획·실셈·체크리스트 사이의 목록 및 주요 조작부 디자인 일관성을 개선했습니다.

[호환성]
기존 시간계획 데이터, 순서 변경, Common Trash 및 각 도구의 주요 데이터 규칙은 유지됩니다.
